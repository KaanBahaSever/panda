Panda 🐼

A tiny, cute YouTube music bot for TeamSpeak 6 — with a lovely web panel.

Works with TeamSpeak 6 Open source No API key ~130 MB RAM
Get started GitHub Download

Why Panda?

SinusBot can't join TeamSpeak 6 servers. Panda can — and it's small, friendly and free.

🐼

Made for TeamSpeak 6

Talks to the server directly. No TeamSpeak client, no X server, no plugins running in the background. TS3 servers work too.

📚

A song library

Every requested song is saved. Favourites start instantly and never hit YouTube again; when it's full, the least played songs make room.

⚡

No waiting

Upcoming songs are downloaded ahead of time, so the next song starts the moment the last one ends.

🎵

Any YouTube link

Song names, youtube.com, youtu.be, YouTube Music, Shorts. Playlist links add just one song instead of loading the whole list.

🌐

A panel you'll like

Now playing, drag & drop queue, search, library, history, volume, loop and seek. Light and dark, English and Turkish, works on phones.

💬

Chat commands

!play, !skip, !queue… in English or Turkish. Limit who can use them with TeamSpeak UIDs or server groups.

🍪

Bot check? Solved.

When YouTube asks to "confirm you're not a bot", paste your cookies in the panel and carry on.

📦

One-line install

One command sets up everything on Linux and keeps yt-dlp up to date. Docker, Windows and macOS builds too.

Your songs, saved

Panda keeps every song you ask for, up to the size you choose (5 GB by default). Saved songs show up in the panel with their play counts, start without any delay and are found by name: !play bohemian plays your saved Bohemian Rhapsody.

When the library is full, the songs you listened to the least are removed first, so your favourites always stay.

Install in one line

On a Linux server (Ubuntu, Debian, Fedora, Arch; x64 or ARM):

curl -fsSL https://raw.githubusercontent.com/KaanBahaSever/panda/main/scripts/install.sh | sudo bash
  1. The installer asks for your TeamSpeak server address and prints the panel address and password.
  2. Open the panel and set the server password and channel under Settings.
  3. Write !play and a song in the bot's channel. That's it! 🎶
Docker 
git clone https://github.com/KaanBahaSever/panda && cd panda
docker compose up -d
docker compose logs panda   # panel password
Windows / macOS

Download Panda from the releases page, install ffmpeg, yt-dlp and deno, then run panda.

Chat commands

Questions

Do I need a YouTube API key?

No. Panda uses yt-dlp, which reads YouTube like a browser does: no API key, no Google project, no daily quota.

Why can't SinusBot join my TeamSpeak 6 server?

TeamSpeak 6 servers only accept TeamSpeak 3 clients from version 3.6.0, and SinusBot runs an older one. Panda speaks the protocol itself and understands the new license data that TeamSpeak 6 sends while connecting.

YouTube says "confirm you're not a bot"

That happens on some server IPs. Log in to YouTube in a private window, export the cookies with a cookies.txt extension, close the window and paste them in Settings → YouTube cookies.

How much does it need?

Very little: the bot uses about 130 MB of RAM, and yt-dlp and ffmpeg only run while a song plays. A small VPS next to your TeamSpeak server is plenty.

Is it free?
